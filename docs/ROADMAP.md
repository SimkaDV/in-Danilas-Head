### Структура проекта

```
docs/                      ROADMAP.md, NOTES.md
public/                    файлы «как есть»: favicon, models/*.glb, audio/
src/
  assets/                  картинки, которые Astro оптимизирует
  components/
    ui/                    кирпичики: Button, ScrollArrow, FeatureCard, InterestCard, ModelCard (дальше Avatar, Pill, Card)
    layout/                каркас: Container, Section, Footer (дальше Header)
    sections/              блоки страниц: Hero, Flagship, About, Catalog
    islands/               React (.tsx): CaseTabs, CatalogFilter (дальше Player, Model3D, игрушки)
  content/                 Markdown: products/, interests/ (позже)
  data/                    данные без разметки: hero.ts, flagship.ts, about.ts, interests.json, catalog.ts (дальше nav.ts, playlists.ts)
  layouts/Layout.astro     общая обёртка страницы
  pages/                   каждый файл = адрес на сайте
  styles/
    tokens.css             ВСЕ переменные (цвета, шрифты, отступы)
    global.css             сброс и базовые стили
```

Папки создаём по мере надобности, не все сразу. Что уже есть на самом деле – в [NOTES.md](NOTES.md).

### Правила кода

- Цвета, размеры и шрифты только через переменные из `tokens.css`, никаких `#8EAE69` в компонентах.
- Слои: ui → layout → sections → pages. Страница собирает секции, секция собирается из ui.
- Контент отдельно от вёрстки (Markdown), данные отдельно (`data/*.ts`).
- React только там, где нужен интерактив.
- Импорты через алиас `@/` (например, `@/components/ui/Button.astro`).
- Именование: компоненты `PascalCase.astro`, страницы и Markdown `kebab-case`.
- Стили компонента в его `<style>` (изолируются сами), мобильная вёрстка с первого дня через `clamp()` и `min()`.
- Плеер без прерывания музыки: `<ClientRouter />` в `Layout.astro` + `transition:persist` на плеере.

### Рабочий процесс (git, Codex, Claude Code)

- Один шаг = один коммит. Перед задачей `git status` чистый.
- Агент делает работу → смотришь изменения → всё хорошо, коммитишь; сломалось, `git restore .` (новые файлы `git clean -fd`).
- Codex не делает commit и push, это делаем мы сами. Claude Code коммитит только по просьбе, push – сами.
- Claude Code работает в отдельных ветках `claude/*` (worktree); в `main` попадает только то, что влили.
- Сообщения коммитов: `feat:` новое, `fix:` исправление, `docs:` документация, `style:` оформление. Заголовок короткий, детали во втором `-m`.
- Один чат с Claude = одна задача, в начале нового чата кидаем NOTES.md.

### Принятые решения

- **Стек:** Astro + React (React-«острова» для интерактива: плеер, 3D-голова, игрушки). Без Framer и без конструкторов.
- **Шрифт:** только Rubik (переменный, с кириллицей), без других шрифтов. Ставится через `@fontsource-variable/rubik`, без загрузки с Google.
- **Палитра (основа):** фон `#8EAE69`; `#4A6938` – «впадины», кнопки, фон шапки с прозрачностью; `#292D25` – массивные опорные элементы; акцент лайм `#D4FB0B`. Сетка-клеточка поверх фона – сделана (4 ноя). У карточек Bento у каждой свой цвет (`--color-interest-*` в ветке Bento), цвета нижнего ряда пока временные.
- **Контент:** файлы в репозитории (коллекции Astro), без платной CMS. Интересы – `src/data/interests.json` + коллекция `interests` (в ветке Bento).
- **Архитектура:** слои ui → layout → sections → pages, токены в одном файле, алиас `@/` (4 ноя 2026).
- **Хостинг:** бесплатный (Vercel или Cloudflare Pages), домен – позже.
- **3D:** на старте фото, дальше интерактивные `.glb` через компонент `Model3D`.
- **Язык:** русский, английский после MVP.
- **Flagship (4 ноя):** рендер пока один на все табы; кнопка ведёт на `#`; цены нет; клякса и активный таб `--color-accent`, карточки `--color-deep`.
- **Название карточки:** в Bento стоит «Музей Сокровищница» (подтвердить, см. открытые вопросы).
- **BRO × BRO SHOP** – отдельный проект, в этот сайт не входит.

### В MVP входит

- Главная: шапка, флагман, блок про меня, свёрнутый Bento, каталог
- Плеер с непрерывной музыкой между страницами
- Каталог: 6 товаров, фильтры, страница товара
- 1–2 страницы интересов (предлагаю: «3D-галерея» и «Винил»)

- Футер, адаптив (десктоп + телефон), мета-теги, деплой
