# Выгрузка с Яндекс Музыки

Скрипт забирает лайкнутые треки и треки из всех твоих плейлистов и сохраняет таблицу `out/tracks.csv` (и `out/tracks.json`). У каждого трека предложен стиль для плеера по жанру альбома: `techno`, `lofi`, `jazz` или `manual` (разобрать вручную). Сами файлы треков скрипт не качает, только список.

## Один раз: окружение

```bash
cd tools/yandex-music
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

## Токен

1. Открой в браузере, где ты вошёл в Яндекс: https://oauth.yandex.ru/authorize?response_type=token&client_id=23cabbbdc6cd418abb4b39c32c41195d
2. Разреши доступ. Тебя перекинет на страницу, в адресе которой есть `access_token=...`. Скопируй значение до `&`.
3. Создай рядом со скриптом файл `.env` с одной строкой:

```
YANDEX_MUSIC_TOKEN=сюда_токен
```

Токен даёт полный доступ к аккаунту Яндекса: никому не показывай, в git он не попадает (`.gitignore`).

## Запуск

```bash
.venv/bin/python export.py
```

В конце скрипт пишет, сколько треков в каждом стиле и какие жанры не распознал. Их можно дописать в `GENRE_STYLE` в `export.py` и запустить ещё раз.

Столбцы: стиль, исполнитель, название, альбом, год, жанр, длительность, лайк, плейлисты, доступен ли трек, ссылка на Яндекс.
