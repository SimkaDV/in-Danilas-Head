# В голове у Даньки

Личный сайт Даньки на Astro + React (React только для интерактивных «островов»).

Заметки, палитра, правила и статус по roadmap: [docs/NOTES.md](docs/NOTES.md).

## Команды

| Команда | Что делает |
| :-- | :-- |
| `npm install` | Ставит зависимости |
| `npm run dev` | Dev-сервер на `localhost:4321` (через агента: `astro dev --background`) |
| `npm run build` | Сборка в `./dist/` |
| `npm run preview` | Просмотр собранного сайта |
